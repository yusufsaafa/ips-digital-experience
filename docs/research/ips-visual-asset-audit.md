## Implementation Guidance From Audit

- Use the Rubbercraft airframe seal as the hero image because it is product-level, technical, and visually communicates engineered polymer work without resorting to generic aerospace imagery.
- Use selective capability imagery only when the visual mapping is direct.
- Use a typeset business identity band instead of logos because logo formats and visual treatments differ across sources.
- Do not add industry images in this pass; the available industry imagery was more likely to be generic end-market photography.
