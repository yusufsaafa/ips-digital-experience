# Task 008: Visual Storytelling System

## Goal

Introduce a credible visual storytelling layer to the IPS homepage using only imagery with a clear connection to Integrated Polymer Solutions or an IPS operating business.

## Scope

- Complete an official-source visual asset audit before implementation.
- Document visual hierarchy, crop rules, captions, accessibility, and fallback behavior.
- Add a hero visual only from an approved official business asset.
- Add a restrained business identity band near the hero.
- Add selective capability imagery only where a verified asset-to-capability mapping exists.
- Preserve the simplified content structure, routing behavior, registry facts, matching logic, external CTAs, and existing Reveal behavior.

## Validation

- `pnpm lint`
- `pnpm build`
- Manual checks for responsive layout, image loading, no horizontal overflow, no console errors, counts, routing interactions, alt text, and reduced motion.
